Meta returns to open source with Muse Glimmer, an Apache 2.0 licensed 30B parameter AI model optimized for agents — available now

VentureBeat – AI · Topic: AI/Cloud/Quantum

  • What it is: Meta released Muse Glimmer, an Apache 2.0 licensed 30B parameter AI model specifically optimized for running autonomous AI agents directly on high-end consumer hardware.
  • Who: Meta, a leading technology giant, developed and open-sourced Muse Glimmer, signifying a strategic pivot back to permissive licensing for its advanced AI models.
  • What it does: This model enables sophisticated AI agents to operate directly on high-end consumer devices like Macs and PCs, reducing reliance on cloud infrastructure for agentic workloads.
